# DevSecOps From Zero — 90-Day Hands-On Track

This folder is a beginner-first learning path for becoming comfortable with cloud, DevOps, and security through practical labs.

## Rule of the course

Do not mark a lab complete until you can show evidence:
- command output
- screenshot
- code/configuration
- or a short explanation in your own words

## 90-day progression

1. Linux and networking fundamentals
2. AWS/cloud fundamentals
3. Git and GitHub workflows
4. Docker and containers
5. CI/CD
6. Terraform and Infrastructure as Code
7. Cloud security and IAM
8. DevSecOps scanning and secure pipelines
9. Kubernetes fundamentals and security
10. Final portfolio project

## How to study each day

1. Read the beginner notes.
2. Type every command yourself.
3. Break something intentionally.
4. Fix it without copying the answer immediately.
5. Write down what happened and why.
6. Complete the checkpoint questions.
